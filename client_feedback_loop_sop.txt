# CLIENT FEEDBACK LOOP: STANDARD OPERATING PROCEDURE
## Minimizing Friction & Maximizing Quality during the 14-Day Sprint.

---

### 1. THE CONSOLIDATED FEEDBACK RULE
To maintain the 14-day velocity, we do not accept piecemeal feedback via email, Slack, or text. All feedback must be delivered via the **Project Command Center** in a single batch per phase.

---

### 2. PHASE-SPECIFIC FEEDBACK WINDOWS
- **Phase 1 (Strategy)**: 24-hour window to approve the Authority Blueprint.
- **Phase 2 (Content/Design)**: 48-hour window to review the live draft.
- **Phase 3 (Final QA)**: 24-hour window for minor "punch-list" items.

---

### 3. HOW TO PROVIDE ELITE FEEDBACK
- **Focus on Goals, Not Personal Taste**: Instead of "I don't like this gold," say "Does this gold communicate the level of authority we discussed in Phase 1?"
- **The 'Why' over the 'What'**: Explain the reasoning behind a request so our strategists can find the best technical solution.
- **Be Decisive**: The 14-day sprint depends on the client's ability to make firm decisions.

---

### 4. INTERNAL REVIEW SOP (For Team)
Before any draft is sent to the client, the Project Manager must verify:
- [ ] Mobile responsiveness (No overlapping text).
- [ ] Button hover states (Text remains visible).
- [ ] Forms are functional (Test submission).
- [ ] All placeholder text is replaced.
- [ ] Image alt tags are set for SEO.

---
*Speed is a byproduct of clarity.*
